Getting started

Invite the bot, sign in, and open your first ticket.

This is the fast path. Ten minutes end to end.

1. Invite the bot to your server

  1. Open the dashboard at dat-one-ticketer.danhost.workers.dev.
  2. Click Invite the bot (or Add to Server). This opens Discord's authorise screen.
  3. Pick your server and approve. The bot needs the permissions it lists - see Permissions if you want to know why.

2. Sign in to the dashboard

  1. On the landing page click Sign in with Discord.
  2. Authorise the app.
  3. You land on Servers (#/). You see every server where you are the owner or have Manage Server - others are hidden.

To sign out later, use the sign-out link in the header.

3. Do the one-minute config

You can do all of this from the dashboard, or from Discord with slash commands.

Open your server in the dashboard and, in General settings:

  • Set Default ticket mode - Private channel or Private thread.
  • Set Default category - where new channel tickets go.
  • Set Staff roles - who is allowed to claim and manage tickets.
  • Set Log channel and Transcript channel (optional but recommended).
  • Click Save settings.

If the server page shows "Add the bot to continue", click Add to Server before anything else - nothing works until the bot is actually in the server.

4. Create your first panel

  1. On the server page, in the Ticket panels card, click + New panel.
  2. Pick a template in Start from a template - Support, Sales, Report a user or Ban appeal - or leave it on Blank.
  3. Set Channel to post in and the Title / Description users will see.
  4. Add at least one Ticket type (a label like General Support).
  5. Click Create panel.

The panel message is posted to the channel you chose. Users can now click it to open a ticket.

5. Test it

Open Discord, go to the panel channel, and click the panel as if you were a user. You should get a private channel/thread with a welcome message and a row of buttons.

Then:

  • Click Claim to take the ticket.
  • Click Close to close it - a transcript is generated and sent to your transcript (or log) channel.
