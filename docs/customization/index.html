Customization overview

How the server, panel and type overrides stack, and what you can change.

The Message & colour customization card appears twice:

  1. On the server page - your server-wide defaults.
  2. In the panel editor - overrides for that panel only.

Each ticket type can also override a few things from its Advanced section.

How overrides stack

Each layer overrides the one before it. So if a value looks ignored, a panel or type is probably overriding the server setting - check those.

Language presets

The Language (default texts) dropdown on the server page loads a preset's text into the fields above it. Supported languages:

CodeName
enEnglish
esEspanol
frFrancais
deDeutsch
ptPortugues

Picking a language writes the welcome title/message, the six system messages and the button labels, then you review and Save settings. The language is stored on the server and is the base layer for every ticket.

Colours

  • Welcome colour, transcript colour and priority colours are stored as numbers. In the customization card you type a #hex value; blank means "inherit" (brand colour for the welcome, red for the transcript).
  • The panel message colour is a separate, decimal field in the panel editor.

The default brand colour is #8B5CF6.
