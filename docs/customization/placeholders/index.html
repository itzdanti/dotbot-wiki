Customization

Placeholders

Every {token} you can drop into a text field, and what it becomes.

Text fields in the customization card - the welcome title/message/footer, image and thumbnail URLs, the system messages, and the transcript title/description/footer - support placeholders.

A placeholder is written in curly braces, e.g. {username}. Anything that isn't a known token is shown literally - so if you see {something} in a message, it wasn't a valid token.

Available tokens

TokenBecomes
{brand}The brand name (dat one ticketer).
{number}The ticket number, e.g. 42.
{user}The opener's user ID.
{username}The opener's Discord username.
{userAvatar}The opener's avatar URL.
{type}The ticket type label (or type - subtype).
{panel}The panel's internal name.
{guild}The server (guild) ID.
{count}Message count (transcripts).
{date}Today's date as YYYY-MM-DD (UTC).
{mention}A mention of the relevant user - the opener when a ticket opens, otherwise the acting user.
{openerMention}A mention of the ticket opener.
{claimerMention}A mention of whoever claimed the ticket.
{closerMention}A mention of whoever closed the ticket.
{name}The new channel name in the Renamed message.

Where each is available

ContextTokens that resolve

Examples

If a token isn't in the list above it is printed as-is. Double-check spelling - {userID} is not the same as {user}.
