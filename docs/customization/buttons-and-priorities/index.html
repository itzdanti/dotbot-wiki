Buttons & priorities

Configure the ticket buttons and the priority list.

Buttons

The Buttons section has one row per action, in the order claim, add, remove, rename, close. Each row has:

ControlNotes
label text boxButton text, placeholder Label.
emoji text boxPlaceholder emoji. Accepts a unicode emoji or a custom one like <:name:id>.
style dropdownPrimary, Secondary, Success, Danger.

ActionLabelStyle

addAdd UserSecondary

The second button row in a ticket (Priority, Tags, Note) has fixed labels and styles - it is not covered by the Buttons section.

Priorities

Used by the Priority button. Note in the UI: Used by the Priority button. Colour is the embed colour when no welcome colour is set.

Each row:

  • emoji box (placeholder emoji)
  • label box (placeholder Label)
  • id box (placeholder id) - a short internal id, e.g. high
  • colour box (placeholder #hex)
  • an x button to remove the row

Button + Add priority adds a row. The first row is the default look.

Defaults

idLabelEmojiColour
lowLow🔽#808080
normalNormal➖#5865F2
highHigh🔼#FAA61A
urgentUrgent🔥#ED4245

New tickets start at normal unless a ticket type overrides the Default priority.

If a ticket references a priority id that no longer exists, the bot falls back to the default priority, then the second priority, then the first.
