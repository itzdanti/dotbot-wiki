Panel templates

The ready-made starting points in the New panel editor.

When you create a new panel, the Start from a template card offers a Template dropdown:

Blank · Support · Sales · Report a user · Ban appeal

Picking one fills in the Panel message fields and the Ticket types below with the values listed here. Everything stays editable afterwards - a template is just a head start.

Blank

Nothing is filled in - you start with an empty panel and no types. Use + Add type to build it yourself.

Templates set the panel title/description/button and the ticket types only. They don't change your messages, colours or priorities - those stay as your server defaults until you override them.
