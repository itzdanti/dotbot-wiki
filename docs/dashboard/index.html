Dashboard

Dashboard tour

The header, the servers list, and how the pages fit together.

The dashboard is where you configure everything. You must be signed in with Discord, and you only ever see servers you can manage.

Header and footer (every page)

Header, left to right:

  • Brand text dat one ticketer with small text by itzdanti.
  • Nav links: Dashboard, Terms, Privacy, Add to Server.
  • A theme button showing light or dark - it flips the whole site theme and remembers your choice in the browser.

Footer:

  • Left: dat one ticketer / itzdanti
  • Right links: ticketer@itzdanti.dev, tg/@itzdanti, status, and the agent prompt.

Navigation map

Every server page shows its four sub-tabs at the top and a Switch server (or Back) button.

Page: Servers (#/)

Heading Servers, then Signed in as <your name>. Pick a server to configure.

  • A grid of server cards. Each shows the server icon, its name, and Owner or Manager.
  • Click a card to open that server.
  • Invite the bot in the top-right adds the bot to a new server.
  • If you manage nothing: You don't manage any servers where you can use this bot.

Page: Server (#/guild/<id>)

The header shows the server icon, its name, and either Bot is in this server or Bot is not in this server, plus a Switch server button.

If the bot is not in the server, an Add the bot to continue card appears first. Click Add to Server and do nothing else until the bot has joined.

The rest of the page is split into four cards:

CardWhat it's for
General settingsTicket mode, channels, roles, naming, language.
Message & colour customizationServer-wide look and wording (details).
Ticket panelsCreate, edit, duplicate and delete panels (details).
Ticket blacklistBlock users from opening tickets.

Sub-tabs

TabPagePurpose
Settings#/guild/<id>Everything in the table above.
TranscriptsTranscriptsSearch and open saved ticket transcripts.
StatsStatsTotals and per-staff claimed/closed counts.
Audit logAudit logReverse-chronological list of changes.

Most fields only take effect after you press Save settings (server page) or Save changes (panel editor). If a change "did nothing", you probably didn't save.
