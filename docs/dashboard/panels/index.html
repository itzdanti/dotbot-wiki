Panel editor

Build panel messages, ticket types, sub-types and per-panel overrides.

A panel is the message users click to open a ticket. You reach the editor from the Ticket panels card on the server page:

  • + New panel opens #/guild/<id>/panel/new
  • Edit on a row opens #/guild/<id>/panel/<pid>

The heading is New panel or Edit panel, with a Back button top-right.

Start from a template (new panels only)

A Template dropdown with: Blank, Support, Sales, Report a user, Ban appeal. Picking one fills the fields and ticket types below with a ready-made starting point. You can still edit everything afterwards. The exact contents of each template are listed on Panel templates.

The Colour (decimal) field on the panel is a plain integer such as 9133302 (that's #8B5CF6, the brand purple). The customization card's colour fields use #hex instead - both work, they belong to different controls.

Dropdown vs buttons

  • Dropdown - one select menu. Up to 25 ticket types. Best when you have several options.
  • Buttons - one button per type. Discord allows 5 buttons per row, so the panel shows at most 5 types in this mode.

Sub-types

A sub-type is a second choice under a ticket type - e.g. type Bug report with sub-types 🐛 Crash | The app closes and 🐌 Slow | It's laggy.

Format each line as:

Blank lines and lines without a label are ignored, and up to 25 are offered. When a user picks a type that has sub-types, Discord shows a second menu so they choose the sub-type before the ticket opens. The sub-type label is stored on the ticket as its subject.

Message & colour customization (per panel)

The same fields as the server-wide card, but these values override the server defaults for this panel only. Intro line: Panel overrides for ticket messages. Values shown merge your server defaults with this panel's own overrides.

See Customization for every field.

Saving

Bottom button: Create panel (new) or Save changes (existing). While saving, Saving... appears next to it. On success you get a Panel saved toast and return to the server page.

Saving posts or updates the panel message and all its ticket types in Discord:

  • New panel: the message is posted to Channel to post in.
  • Existing panel: the existing message is edited in place. If that fails - for example the message was deleted - the bot re-posts a fresh one.

Duplicate and delete

On the server page each panel row also has:

  • Duplicate - copies the panel and all its types, then opens the copy so you can rename it.
  • Delete - asks Delete this panel and its message?, removes the Discord message, and deletes the panel and its types.

You can also manage panels from Discord with /panel.
