Settings

Every field in the General settings card and the server-wide customization card.

The server page (#/guild/<id>) starts with two cards that hold your server-wide defaults.

Every dropdown that is optional defaults to -- none --.

Button below the card: Save settings. Nothing is stored until you press it.

Naming scheme tokens

The Naming scheme field (and the per-type naming field) accepts:

TokenBecomes
{number}the ticket number, e.g. 42
{username}the opener's Discord username
{user}the opener's user ID
{type}the ticket type label (or type - subtype)

Anything that isn't letters, digits, - or _ is replaced with -, everything is lowercased, and the result is capped at 90 characters. Example: {type}-{username} → bug-report-jane.

Language presets

Picking a language immediately writes that language's preset text into the customization fields below it - the welcome title/message, the six system messages and the button labels. Review them, then press Save settings.

Message & colour customization

This card sets the server-wide look and wording. Panels and ticket types can override any of it. It contains:

  • Welcome message - colour, title, message, footer, thumbnail URL, image URL, and a Show "Opened by" line checkbox.
  • Buttons - label, emoji and style for claim, add, remove, rename and close.
  • Priorities - add/edit/remove rows of emoji + label + id + colour.
  • Mention pings - ping the opener, plus comma-separated role IDs to ping.
  • System messages - claimed, renamed, member added, member removed, ticket closed, transcript saved.
  • Transcript embed - colour, footer, title, description.
  • Closing behaviour - DM the opener a copy, delete the channel on close.

These fields are documented in full, field by field, in Customization, including the placeholder tokens you can use.

Text fields accept {placeholders}. Anything that isn't a real placeholder is shown literally - see Placeholders.

Ticket blacklist

Text: Blacklisted users cannot open tickets. Use their Discord user ID.

  • User ID text box (placeholder 123456789012345678)
  • Reason (optional) text box
  • Blacklist button

Below, each blocked user shows their ID (and reason) with a Remove button. Empty state: Nobody is blacklisted.

A blacklisted user who clicks a panel gets an ephemeral message telling them they're not allowed, including the reason if you set one.
