Troubleshooting

Common symptoms and exactly how to fix them.

Dashboard

SymptomFix
No servers on the Servers pageYou need to be the owner or have Manage Server on the server.
Bot is not in this server in the dashboardClick Add to Server on that server's page and let the bot join.
Sign-in returns to the landing page and does nothingYour Discord session expired - sign in again. If it says the sign-in expired, the Discord token lapsed; re-authorise.
A panel shows not postedOpen it and press Save changes to post it to the channel.
A changed setting had no effectYou may not have pressed Save settings / Save changes.
A panel/type value seems ignoredPanels and types override server defaults - check the panel and its types.
The theme resetsThe choice is stored per-browser; a different browser or a cleared cache resets it.

Opening tickets

SymptomFix
Nothing happens when a user clicks the panelMake sure the bot was invited with the permissions it asks for (Permissions).
You're not allowed to open tickets...The user is on the blacklist.
You already have N open ticket(s)Raise Max open tickets per user or have them close a ticket.
Sorry, I couldn't create your ticket: ...Usually a missing category or a permission problem in the ticket category. Check the category and the bot's permissions.
Panel shows no optionsThe panel has no ticket types, or you used Buttons style with more than 5 types. Use Dropdown for more than 5.
The second (sub-type) menu never appearsThe type has no sub-types, or they failed to parse. Format is emoji label | description, one per line.

Staff actions

SymptomFix
Only staff can...You need Manage Channels, or a role listed in Staff roles / Admin roles.
You need the **Manage Server** permission...Same - the command is staff-gated.
This channel isn't a ticket.The command only works inside a ticket channel that the bot created.

Transcripts & closing

SymptomFix
No transcript posted on closeSet a Transcript channel (or Log channel). The transcript is still saved and reachable in the Transcripts tab.
Transcript is missing the last messagesTranscripts are capped at 2000 messages; very large tickets are truncated.
The opener didn't get a DM copyThey have DMs closed. Turn on DM the opener a copy and/or check their privacy settings.
Internal notes are missingThat's by design - notes are never in transcripts. They're posted to the log channel and stored on the ticket.

Messages & text

SymptomFix
Text shows {something} literallyThat token isn't a valid placeholder.
My colour change did nothingCheck the panel and ticket type overrides - they beat the server setting.
The bot's messages are in the wrong languagePick the language again, review the text, and press Save settings.
