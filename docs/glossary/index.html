Glossary

The words dat one ticketer uses, and what they mean.

Admin role : A higher-tier staff role. Admins additionally get Manage Channels inside channel tickets.

Audit log : A reverse-chronological record of settings, panel, blacklist and ticket changes, each with an actor ID and timestamp.

Blacklist : A list of users who cannot open tickets in a server.

Button panel : A panel that shows one button per ticket type (max 5).

Channel ticket : A private channel created for a single ticket.

Claim : A staff member marking themselves as handling a ticket.

Customization : The messages, colours, buttons and priorities that shape how tickets look and read. Set server-wide, per panel, and per type.

Dropdown panel : A panel that shows a select menu of ticket types (max 25).

Internal note : A staff-only note on a ticket. Never shown to the opener and never included in transcripts.

Panel : A message in a channel with a dropdown or buttons that opens tickets.

Placeholder : A {token} in a text field that is replaced with a real value, e.g. {username}.

Priority : Low / Normal / High / Urgent (or your own list). Used by the Priority button and shown on the welcome embed.

Staff : Anyone with Manage Channels, or any role listed in Staff roles or Admin roles.

Sub-type : A second choice under a ticket type, e.g. Bug report → Crash.

Tag : A short free-text label staff can put on a ticket.

Ticket : A single support conversation, opened from a panel and living in its own channel or thread.

Ticket type : One option on a panel, e.g. General Support or Sales.

Transcript : A styled HTML copy of a ticket's messages, generated when the ticket closes.

Thread ticket : A private thread created for a single ticket (auto-archives after 7 days; archived + locked on close).
