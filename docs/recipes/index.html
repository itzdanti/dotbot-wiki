Setup recipes

Four complete configurations you can copy - support, reports, sales and appeals.

These are working configurations built only from fields that exist in the dashboard. Pick the one closest to your server, then adjust names and channels.

Staff bypass all open-ticket limits, so you can test any of these yourself without hitting the per-user caps.

1. Simple support desk

The default shape: one dropdown, private channels, one staff role.

General settings

Press Save settings.

Panel

  1. + New panel → template Support.
  2. Channel to post in: #support.
  3. Ticket mode: Private channel.
  4. Panel style: Dropdown.
  5. Keep the template types (General Support, Bug Report, Billing) or edit them.
  6. Create panel.

Users pick a type, get a private channel, and your Support role is pinged. Closing deletes the channel and posts the transcript to #transcripts.

2. Moderation reports

Reports need to be quiet - a panel in a public channel, but tickets only visible to the reporter and moderators.

Panel

  1. + New panel → template Report a user.
  2. Channel to post in: #report-a-user (or a read-only info channel).
  3. Ticket mode: Private thread.
  4. Thread parent channel (thread mode): the channel that should hold the threads (often the panel channel).
  5. Panel style: Dropdown.
  6. Leave the template types (Harassment, Spam, Other).
  7. In each type's Advanced, set Staff roles to Moderator and Max open per user for this type to 1 so one report cannot flood the queue.
  8. Create panel.

Private threads are only visible to the opener, the bot, and members with Manage Threads - staff roles alone are not added automatically. Give your moderators Manage Threads, or have them use Add User on a report. If you would rather not hand out that permission, use Private channel mode instead - channel tickets grant your staff roles access directly.

3. Sales enquiries

Keep sales separate from support so the right role is pinged and the numbers stay clean.

General settings

  • Create a Sales role in Discord and a Sales Tickets category.
  • Leave the global naming scheme alone; override it per ticket type on this panel.

Panel

  1. + New panel → template Sales.
  2. Channel to post in: #sales.
  3. Ticket mode: Private channel.
  4. Category for new tickets: Sales Tickets.
  5. In each type's Advanced: Staff roles = Sales, Naming scheme = sales-{number}.
  6. Default priority: high for New Order, leave normal for questions.
  7. Create panel.

Because the panel and each type carry their own Staff roles, only the sales team needs to see these tickets. Panels and types override the server-wide staff list.

4. Ban appeals

Appeals are one-per-user, reviewed by admins, and usually worth keeping readable after closing.

Panel

  1. Start from the Ban Appeal template.
  2. Channel to post in: #appeals.
  3. Ticket mode: Private channel with a dedicated Appeals category (simpler staff access than private threads).
  4. In the type's Advanced, set Staff roles to your appeals team, Admin roles to Admin, and Max open per user for this type to 1.
  5. Add a Welcome message override asking for the case ID and the reason given.
  6. Create panel.

Closing behaviour (Customization → Closing behaviour): turn Delete the channel on close off if you want to keep the closed channel around. It is then renamed closed-<number>; the transcript is saved either way.
