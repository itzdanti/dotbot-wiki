Permissions & access

What the bot asks for when you invite it, and who can do what.

Bot permissions

When you invite the bot it asks for a fixed set of permissions. You don't have to configure them - just approve the invite screen:

PermissionWhy the bot wants it
View ChannelSee the channels it works in.
Send MessagesPost panels, welcome messages and system messages.
Embed LinksSend embeds (panels, welcome, transcript).
Attach FilesAttach transcripts.
Read Message HistoryRead a ticket to build its transcript.
Manage ChannelsCreate ticket channels and set their permissions.
Manage RolesApply role permissions on ticket channels.
Manage MessagesPerform staff actions inside tickets.
Use External EmojisUse custom emoji in panels and messages.
Manage ThreadsCreate and manage thread tickets.
Create Private ThreadsOpen private thread tickets.
Send Messages in ThreadsPost inside thread tickets.

You can grant Administrator instead, but the set above is all it needs and is safer.

Who can use the dashboard

You can open a server in the dashboard if you are:

  • the server owner, or
  • someone with the Manage Server permission (or Administrator).

Servers you don't manage simply don't appear.

Who counts as staff in Discord

The bot treats you as staff if either is true:

  • you have the Manage Channels permission, or
  • you hold a role listed in Staff roles or Admin roles.

Staff can claim, rename, add/remove users, set priority, add tags and notes, and use /panel, /config and /blacklist.

Admin roles are a higher tier - on channel tickets they're given Manage Channels inside the ticket, and they act as the fallback when a ticket type doesn't define its own admin roles.

Opening tickets

  • A user on the blacklist cannot open tickets at all.
  • Regular users are limited by Max open tickets per user and by any per-type cap.
  • Staff bypass these limits, so they can always open a ticket to test.
